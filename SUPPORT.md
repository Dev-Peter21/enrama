# Support

Enrama's generator, CLI/preview and two themes are available from the repository.
Version `0.1.0` is prepared but not published to PyPI; the visual editor remains
planned for 0.2. See the [local workflow](docs/local-demo.md) and
[release preparation](docs/release-preparation.md).

After the first public release, the latest patch of 0.1.x will be maintained
until 0.2.0 is published. Older patches should upgrade to the latest patch;
there is no parallel LTS promise or fixed release cadence. No production release
is supported or claimed available before it actually ships.

- Read the [documentation index](docs/README.md) for product and design questions.
- Search [existing issues](https://github.com/Dev-Peter21/enrama/issues) before
  opening a new one.
- Use the question template for clarification, the bug template for a
  reproducible documentation or software defect, and the feature
  template for a product proposal.
- Report vulnerabilities through [SECURITY.md](SECURITY.md).
- Raise community concerns through [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

English and Spanish are welcome in discussions. Include a minimal example
without personal or client data. Volunteer support has no guaranteed response
time; commercial support or managed hosting is not offered by this project.
