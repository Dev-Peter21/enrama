# Support

Enrama **0.1.0** is available on [PyPI](https://pypi.org/project/enrama/0.1.0/), with
a matching [GitHub Release](https://github.com/Dev-Peter21/enrama/releases/tag/v0.1.0).
It includes the generator, CLI/preview and minimal/bold themes for Python 3.12–3.15.
Start with the [installation instructions](README.md#install-and-create-a-page)
or the [source workflow](docs/local-demo.md). The visual editor remains planned
for 0.2; a tested client Pages recipe and final MVP acceptance are still pending.

The latest patch of 0.1.x is maintained
until 0.2.0 is published. Older patches should upgrade to the latest patch;
there is no parallel LTS promise or fixed release cadence. Currently that patch
is 0.1.0. A development checkout is not evidence that a newer release exists.

- Read the [documentation index](docs/README.md) for product and design questions.
- Search [existing issues](https://github.com/Dev-Peter21/enrama/issues) before
  opening a new one.
- Use the question template for clarification, the bug template for a
  reproducible documentation or software defect, and the feature
  template for a product proposal.
- Report vulnerabilities through [SECURITY.md](SECURITY.md).
- Raise community concerns through [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

For a software issue, include `enrama --version`, Python version, operating
system, installation method and a minimal YAML example with the full diagnostic.
Check the [changelog](CHANGELOG.md) and [0.1.0 verification](docs/verification/r03-release.md).

English and Spanish are welcome in discussions. Include a minimal example
without personal or client data. Volunteer support has no guaranteed response
time; commercial support or managed hosting is not offered by this project.
