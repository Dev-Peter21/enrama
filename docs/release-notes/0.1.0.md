# Enrama 0.1.0

Generate self-hosted link-in-bio pages from YAML. The generated `dist/` contains
static HTML, CSS and images and needs no Python, API, account or database in production.

- Python 3.12–3.15; MIT license.
- `init`, `validate`, `build` and foreground loopback `preview` commands.
- Strict YAML v1 profile, links, socials, themes and local assets; local JSON Schema
  for editor assistance.
- Responsive `minimal` and `bold` themes, semantic HTML, SEO/Open Graph metadata
  and licensed controlled icons.
- Bounded safe YAML/image loading, escaped text, confined local assets,
  repeatable static output and guarded output replacement/recovery.

## Installation and use

After this release is published and verified on production PyPI:

```console
uvx --from enrama==0.1.0 enrama init my-links
cd my-links
uvx --from enrama==0.1.0 enrama validate
uvx --from enrama==0.1.0 enrama build
uvx --from enrama==0.1.0 enrama preview
```

Edit `enrama.yaml`, then restart preview to rebuild. Deploy only `dist/` to an
independently chosen static host. The verified client GitHub Pages recipe remains
R04 work. The local visual editor is planned for 0.2.

Support covers the latest 0.1.x patch until 0.2.0 is published, without a fixed
maintenance cadence or SLA. See the repository's security and support policies.
The attached files preserve the reviewed canonical bytes and preparation
provenance; publishing approval is a separate Actions/environment record.
