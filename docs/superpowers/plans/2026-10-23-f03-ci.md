# F03 CI implementation plan

> **For agentic workers:** Use superpowers:executing-plans inline. Follow TDD
> for helper behavior and use actual Actions runs to verify workflow behavior.

**Goal:** Implement issue #4 on develop with seven passing required jobs.
**Architecture:** A single Actions workflow has one quality job and a six-entry
verification matrix. Small standard-library CI helpers validate the interpreter,
JUnit results and artifact evidence; existing packaging tests verify installs.
**Tech stack:** CPython 3.12–3.15, uv 0.13.5, pinned official Actions.
**Spec:** [Accepted CI design](../../continuous-integration.md).

## Global constraints

No CLI/generator changes, PyPI upload, release, deployment, or merge into main.
Linux 3.12–3.15 plus macOS/3.12 and Windows/3.12 are mandatory. Quality uses
Linux/3.12. Preserve runtime dependencies, package version, and lockfile.
The user explicitly authorized implementation on develop; execute inline.

## Review focus

- Wrong interpreter selected despite a correct matrix label: assert both job
  and consumer interpreter versions; negative helper test.
- Zero/all-skipped/failed or absent JUnit report: reject with nonzero status;
  parameterized real report tests, including valid positive suite.
- Missing distribution/report after successful commands: require both formats
  and produce hashes; missing-archive negative tests.
- Failure hidden by reporting or matrix cancellation: keep fail-fast false,
  no continue-on-error, test a failing PR run and subsequent successful revision.
- Windows paths/encoding and independent installs: run the actual six-platform
  matrix, with no editable/PYTHONPATH shortcuts or expected-platform waivers.
