# G02 Rendering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement issue #9's in-memory shared HTML renderer on develop without builder, CLI or visual theme work.

**Architecture:** C01 configuration and matching G01 snapshots feed a checked in-memory image binding map, then a primitive presentation context and trusted packaged Jinja2 base. Structured failures distinguish integration/template defects from real package-resource I/O; the caller owns output and exits.

**Tech Stack:** Python 3.12+, uv, Jinja2/MarkupSafe, pytest, Ruff, strict mypy, existing Hatchling distributions and F03 matrix.

**Spec:** [Approved G02 contract](../../rendering.md), [G01](../../assets.md), [C01](../../configuration.md), [F01](../../cli-contract.md). Approved contract revision a0adba6782949a20497224498936d81a491a892b.

## Global Constraints

- Work directly on the authorized develop checkout; version 0.1.0.dev0. No builder, CLI, final theme presentation, schema change, release or PyPI upload.
- Consume EnramaConfig/PreparedAssets, return a complete string; no YAML reload, image reads/validation/copying, client-tree inspection, writes or implicit network.
- Trusted packaged template only; explicit HTML autoescape, StrictUndefined, LF output, deterministic content, no input mutations.
- One main/h1, optional decorative avatar/nonempty bio, separate enabled links/socials lists in their own order, links first; visible title/effective label, valid profile-only page.
- Shared base for minimal and bold without CSS/icons/scripts. Language from C01, UTF-8/viewport, title/description/basic OG; optional directory canonical/og:url, absolute og:image only with base and image, relative avatar/favicon. No base element/fallback/locale guessing/new tabs/tracking.
- Preserve validated destination/base spelling except directory slash derivation. Public image paths are canonical G01 names with role-correct suffixes and matching field/reference/asset membership.
- Safe English structured internal/operational errors, fail first, no partial output/printing/exits; unexpected defects internal70, actual packaged-resource I/O operational3, interrupts propagate.
- Preserve explicit wheel/sdist inventories, schema drift check, locked tools/build constraints and all six CI verification environments.

## Review Focus

- Optional OG image still needs matching preparation without site.url: pin mismatch rejection before metadata omission in Task1/2.
- Forged duplicate/extra binding or unsafe/missing asset path must not become HTML: Task1 covers field-set/reference/path/role/membership relationships without image hashing.
- Packaged loader must distinguish missing resource from denied I/O rather than let Jinja conflate both: Task2 uses real packaged loading and injected read failures.
- Already-escaped entities and Markup-like validated text must remain plain content in body and attribute contexts: Task2 parsed-output cases cover quotes/entities/template-looking strings.
- Installed resource availability and local resource URL resolution must work away from checkout/production base: Task3 covers isolated installs and root/subpath HTTP requests.
