# Reusable Docker implementation plan

**Approved design:** Generic public Enrama CLI and static runtime images in GHCR, identified by source SHA and digest. Private Grow/Deco content stays in the consumer repository and local images. No Cloud Run services, GCP registries, DNS, billing, credentials or grants changed. Keep loopback preview default. Use isolated checkouts; originals are clean at 7953e90 (Enrama) and 344fa37 (Amapola), remote consumer 3937c11 preserves updated logos/links.

**Architecture:** Bind only the selected client directory at /site with the caller UID/GID. This writable parent permits .enrama locks and atomic sibling dist renames without weakening recovery/collision checks. Never mount dist alone or a repository/host root. Read-only container root and dropped capabilities. Ship a downloadable SHA-pinned Compose template, no OCI bind mounts. Separate Python CLI build stage from nginx static runtime; non-root, PORT and SIGTERM support.
