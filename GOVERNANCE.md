# Governance

Enrama is maintained by [@Dev-Peter21](https://github.com/Dev-Peter21), who owns
the repository and makes final scope, compatibility, merge, and release decisions.
Contributors can propose changes through issues and pull requests.

The [product definition](docs/product.md) sets scope. The
[decision log](docs/decisions.md) records accepted choices and unresolved
questions. Material architectural or public-contract changes should be discussed
in an issue and documented before implementation.

Roadmap task IDs identify planned work; they are not GitHub issue numbers.
When tasks are published as issues, link both records and preserve dependencies
and acceptance criteria. A task is complete only when its criteria have evidence.

No release cadence, long-term support commitment, or service-level agreement
is established. Additional maintainers and changes to governance will be
announced through repository documentation.
